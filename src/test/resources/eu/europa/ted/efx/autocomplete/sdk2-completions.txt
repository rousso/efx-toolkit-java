# The completion items EfxAutocomplete gives for SDK 2, one per line:
#   KIND label(name TYPE, ...) -> TYPE
# where a parameter is marked ? when it is optional and ... when it repeats; keywords and
# properties have no parameter list.
#
# Order: the functions in the order of the signature catalogue, BuiltIns.getAll(), enum by enum
# (LogicalOperators, StringFunctions, NumericFunctions, DateTimeFunctions, ConversionFunctions,
# SequenceFunctions, TemplateFunctions), each built-in's overloads in their order, and an overload
# over T once per value type in the order T knows them (text, indicator, number, date, time,
# duration); then the keywords and the properties, in the order of EfxKeyword and
# EfxLinkedProperty.
#
# Written once from the hand-written list it replaces (EfxBuiltInFunction, deleted in P5.1), with
# the changes the P5.1 design lists: 27 functions added, 4 items changed, count of a node left out.
