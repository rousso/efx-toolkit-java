H0 to H7 complete the plan; H8 to H16 come from Yannis's review of the branch. H10 to H15 apply the rule he agreed on 2026-11-04 for overloads and generic signatures: one generic signature when a construct takes every value type and treats them all alike; overloads only when the type changes what happens (only some types are accepted, or the result differs); a pair `(T)` and `(T*)` when a single value and a sequence give different results, the more exact one winning; which script generator method a built-in calls is never a reason for overloads.
